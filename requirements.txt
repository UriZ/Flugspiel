# *download* is sha256-pinned (SOURCES in src/brain/connectome.py) while the parsers that
# read it are not. `pip-compile --generate-hashes` or `uv lock` would close that.

# >=14.0.1 clears CVE-2023-47248 (arbitrary code execution deserialising an Arrow IPC
# stream — exactly the _edges()/feather.read_table() path); >=17.0.0 clears
# CVE-2024-52338; >=23.0.1 clears CVE-2026-25087 (use-after-free reading an IPC file
# with pre-buffering). `pyarrow>=14.0` admitted every one of those: a fresh install
# resolves to the newest release, but an environment that *already* has an old pyarrow
# (a common transitive dependency of data/ML stacks) satisfies the constraint and pip
# installs nothing.
pyarrow>=23.0.1,<26
